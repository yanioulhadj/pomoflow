# 🍅 Pomoflow

Application web pour travailler avec la méthode Pomodoro.

## Fonctionnalités (v1)

- Minuteur **Focus** (25 min), **Pause courte** (5 min) et **Pause longue** (15 min)
- Enchaînement automatique : après un focus → pause courte, et pause longue toutes les 4 sessions
- Signal sonore en fin de session, temps restant affiché dans l'onglet
- Barre d'espace pour démarrer / mettre en pause
- Liste de tâches : ajout avec estimation de pomodoros, tâche active, tâches terminées
- Sauvegarde automatique dans le `localStorage`

## Lancer le projet

```bash
npm install
npm run dev
```
